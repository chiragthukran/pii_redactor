Runs the same detection logic as the CLI version — regex for structured fields (email, phone, IP, SSN, credit card, DOB), spaCy NER for names/companies/addresses. See the project README for known false positives/negatives before relying on this for anything sensitive.

Why the first run is slow: this page loads instantly, but the redaction itself runs on a backend function that has to load an AI language model into memory before it can process anything. If the server has been idle for a while, that setup happens fresh on your request — usually a few seconds, sometimes up to 30–60s for a long document. Once it's warmed up, repeat runs are faster, until it goes idle again.
